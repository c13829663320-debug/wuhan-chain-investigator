# 江城链察可下载材料

- [skills.xlsx](skills.xlsx)：15项技能清单，以及5个工具岗位和6条运行规则。包括输入、输出、触发方式、服务对象、量化标准与验证说明。
- [skills.csv](skills.csv)：同一份明细，UTF-8 BOM编码。
- [catalog.json](catalog.json)：实际能力目录与量化公式。

表中的指标描述当前程序如何验收，不是检测真实攻击的准确率。公开样本、规则阈值与合成用例分开说明。所有岗位由确定性Python工具执行，没有连接大模型；由用户提交触发，没有每日自动巡链排班。

实时调查回执在页面单独下载，包含资料时点、证据和限制；导入页面可以离线复核。部署目标为 <https://wutiantian.cn/eth-investigator/>，本材料制作时部署待核验。


## 独立交付

网页页脚提供本项目的可编辑 PPT、PDF、使用说明和独立源码下载。源码包排除运行数据库、部署凭据和其他项目内容；在干净目录执行 `npm ci` 后可单独构建。修改后先运行 `python3 scripts/package-source.py` 更新源码下载包，再运行 `npm run build`。
